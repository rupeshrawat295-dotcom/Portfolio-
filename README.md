## Tech Stack

- **Markup & Styling:** HTML5, CSS3 (Modern Flexbox/Grid), Tailwind CSS
- **Interactivity:** Vanilla JavaScript (ES6+)
- **Hosting & CI/CD:** GitHub Pages / Vercel, GitHub Actions

---

## Key Features

- **Responsive Design:** Mobile-first layout with fluid breakpoints across phones, tablets, and desktops.
- **Theme Switcher:** Persistent light/dark mode preference saved in `localStorage`.
- **Accessible & Fast:** Semantic HTML structure targeting high accessibility and SEO ratings.
- **Dynamic Projects Section:** Clean modular cards displaying project tags, live demos, and source code links.
